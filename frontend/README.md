# Smart Tuition Student Management System (Frontend)

Frontend application for the **Smart Tuition Student Management System (STSMS)** built with **React + Vite**.

## Prerequisites

- Node.js 20+
- npm 10+

## Getting Started

From the repository root:

```bash
cd frontend
npm install
npm run dev
```

The app will start on the local Vite development server (typically `http://localhost:5173`).

## Available Scripts

- `npm run dev` - Start the development server
- `npm run build` - Create a production build
- `npm run preview` - Preview the production build locally
- `npm run lint` - Run ESLint checks

## Project Context

This frontend is part of the STSMS project developed for tuition institute management, including modules such as student, teacher, class, attendance, examinations, payments, and reporting.
